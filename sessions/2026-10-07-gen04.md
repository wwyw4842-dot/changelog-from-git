# GEN-04 Polyglot concurrency and cancellation evidence

Scope: PG-05/06/07 only. Roman, Lychee, and GEN-03 storage/release work are excluded.

## Reproduction and implementation

The historical immersive controller started one Promise.all per observer callback. A burst of four callbacks for 24 visible blocks could therefore create 24 concurrent requests even though each batch was six. It also retained no request generation, so a late response could render after stop/re-enable or SPA URL navigation. Deep selection and input enhancement streams similarly accepted late port messages after a newer target replaced the old one.

Both repositories now share the same mechanism:

- `src/content/immersive/controller.ts`: FIFO queue, six logical in-flight slots, per-block deduplication, bounded transient retry, generation-bound AbortController, and URL polling/reset for SPA navigation.
- `src/content/immersive/request.ts`: stream port request with AbortSignal, timeout, disconnect cleanup, and done/error settlement.
- `src/background/request-budget.ts` plus `handlers/stream.ts`: one service-worker budget of six across tabs/ports; queued requests are abortable; replacing or disconnecting a port aborts the provider signal and releases the lease only when the provider path settles.
- `src/content/controllers/selection.ts`, `shortcuts.ts`, `inputEnhance/controller.ts`: generation/target checks and explicit abort on Escape, focus change, stop, and teardown.

## Validation

- Unit: immersive queue/retry/navigation/stale-response tests 4/4; shared background budget tests 2/2; full Vitest 60/60 (including the new tests).
- Lint and TypeScript/Vite production build pass in both repositories.
- Real Chromium MV3 E2E: existing suite 3/3 in each repository; new immersive bounded-concurrency and SPA navigation test 1/1 in each repository. Context route observed peak <= 6 and stale hosts were removed on navigation.

Remaining: protected GitHub CI, review/merge, packaged release/install, and 30-minute/24-hour observation. Real provider accounts were not used; the E2E provider is a controlled Google endpoint response. Do not mark GEN-04 fully released until those gates pass.
