# 2026-05-21 — Polyglot — 修复暗色模式文字对比度低的问题

**Agent**: Antigravity (Gemini 3.5 Flash)
**任务**: 解决划词翻译气泡（Bubble）在白色/浅色网页背景下，且系统处于暗色模式时，由于 Tailwind `darkMode: "class"` 配置缺失 `.dark` 容器类导致部分文字和按钮样式呈现浅色，但背景却被 `prefers-color-scheme: dark` 强制渲染为深色，从而引起文字对比度极低、难以看清的问题。

## 做了什么
- **定位根本原因**：
  - 气泡气泡宿主（`BubbleHost.ts`）在 Shadow DOM 内部创建了 `.poly-root` 根容器。
  - 在 `tailwind.config.ts` 中设置了 `darkMode: "class"`，但由于 Shadow DOM 中没有给 `.poly-root` 应用 `.dark` 类，且外部 `<html>` 或 `<body>` 的 `.dark` 无法穿透 Shadow DOM，导致所有 hardcoded 颜色类（如 `text-[#1a1612]`、`text-[#867566]` 等）都只能解析为浅色（light-mode）样式。
  - 而 `bubble.css` 使用 `@media (prefers-color-scheme: dark)` 独立触发了容器的暗色背景（`rgba(46, 38, 31, 0.95)`），混合在一起造成“黑底黑字”的严重对比度缺陷。
- **高对比度 CSS 覆盖修复**：
  - 在 `bubble.css` 的 `@media (prefers-color-scheme: dark)` 媒体查询下，添加了一套针对 hardcoded Tailwind text/bg/border 类的高特异性 CSS 覆盖规则。
  - 将译文文字（原 `#1a1612`）覆盖为高对比度温暖乳白（`#f1ede8`），原文文字（原 `#867566`）覆盖为温暖浅灰（`#c5b5a5`），正文解读覆盖为 `#e3dcd2`，标签前缀覆盖为 `#867566` 等。
  - 覆盖了详情面板背景（`bg-[#fbf6f1]`）为更协调的深褐色（`#241d18`），并对操作按钮（ActionBtn）、白名单开关及同义词 tag 做了全面的暗色匹配及高对比度样式微调。
- **构建与测试全线跑通**：
  - 运行 `npm run build`，打包编译无报错。
  - 运行 `npm run test`（Vitest 单元测试）通过全部 8 个测试套件（31 项测试）。
  - 运行 `npm run test:e2e`（Playwright E2E 自动化测试）通过 bubble 及 options 设置的所有自动化流程。

## 关键决策
- **选择 CSS 精准强力覆盖**：相较于重构整个 Bubble 组件的 React 类名以适应 dynamic theme，直接在 `bubble.css` 中利用 `@media (prefers-color-scheme: dark)` 对特定的 Tailwind 编译后类名（如 `.text-\[\#1a1612\]`）进行 `!important` 覆盖更加安全、改动域极窄，且能 100% 保持在 Shadow DOM 内生效，绝无样式泄露风险。
