# 2026-05-26 — Polyglot — 手动深色模式与翻译气泡极致沉浸式适配修复 (v2.0)

**Agent**: Antigravity (Gemini 3.5 Flash)
**任务**: 解决用户在“设置中心”将主题选择为“深色”时，部分 UI 界面不适配的问题，精简划词翻译的层级与结构，并发布版本号升级为 v2.0。具体包含：
1. **设置页顶部 Header 栏**：解决开启深色后 Sticky Header 依然保持亮色/浅米色背景的问题（因 Tailwind 透明度修饰类如 `bg-cream-100/80`、`border-cream-300/70` 缺失覆盖）。
2. **划词翻译气泡（Bubble）手动深色模式**：打通 Shadow DOM 隔离环境，让气泡组件能感知并应用手动切换的“深色”模式。
3. **翻译引擎与内容前缀精简（沉浸式体验）**：
   - 彻底移去气泡卡片 Header 中展示的 `· Google` 等引擎提供商标识（降低视觉冗余，符合沉浸式规范）。
   - 保留划词后的“译”字圆形浮动触发气泡（防止划词时无条件直接弹出翻译面板造成干扰，恢复为点击触发）。
   - 精简气泡卡片内部的“译文”和“原文”前缀标签，让翻译内容和原文裸呈，带来极致无噪的排版。
4. **版本发布**：升级项目主版本号至 `2.0.0`（v2.0 阶段性里程碑）。

## 做了什么

- **版本号升级**：
  - 更新 [package.json](file:///d:/developer/my%20project/translate%20plugin/package.json) 和 [manifest.config.ts](file:///d:/developer/my%20project/translate%20plugin/manifest.config.ts)，将项目版本号从 `1.0.0` 正式晋升为 `2.0.0`。

- **精简气泡面板 Header 及文本前缀**：
  - 在 `src/content/bubble/Bubble.tsx` 中，完全去除了 Header 面板中展示的 `· {provider}` 引擎服务商标识，仅在处于 `streaming`（流式中）或 `fromCache`（缓存）状态时进行状态提示。
  - 精简了 Card 中的 `译文` 与 `原文` Row 标签。重构底层 `Row` 组件，使 `label` 属性变为 Optional（可选）。不传入 label 时，底层内容将直接左对齐铺满，获得更开阔的排版阅读感。
  - 清理了未使用的 `provider` 析构变量，保证 TypeScript 编译器不报 `TS6133` 警告。

- **保留“译”字浮动触发按钮**：
  - 在 `src/content/controllers/selection.ts` 中保留 `host.showTrigger`，在用户划词后先浮现“译”字气泡，点击后再展开翻译面板，避免直接翻译在日常复制操作中造成过度干扰。

- **修复全局 theme.css 手动深色下的透明度类失效**：
  - 在 `src/shared/theme.css` 的系统级暗色 and 手动暗色（`html[data-poly-theme="dark"]`）覆盖块中，全面补齐了 10 个缺失的带透明度修饰符的 Tailwind 颜色类（如 `bg-cream-100/80`、`bg-cream-50/70`、`border-cream-300/70`、`border-cream-300/80` 等），还原了暗褐色莫兰迪色系。

- **打通 Shadow DOM 手动暗色模式（JS + CSS 双端协同）**：
  - **JS 同步**：在 `src/content/bubble/BubbleHost.ts` 中新增 `setTheme(theme)` 方法，动态将 `data-poly-theme` 属性挂载到 Shadow Host 元素（`hostElement`）上。并在 `src/content/bootstrap.ts` 初始化及 `chrome.storage.onChanged` 监听到设置变化时主动拉取或同步该属性。
  - **CSS 镜像**：在 `src/content/bubble/bubble.css` 尾部，通过 `:host([data-poly-theme="dark"])` 伪类，完整复制并镜像了 `@media (prefers-color-scheme: dark)` 下的全部暗色规范，解决了 Shadow DOM 样式穿透问题。

- **打包与验证**：
  - 运行 `npm run build`，打包编译 100% 成功，所有资源均以新版本 `2.0.0` 正常输出。
